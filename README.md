# Tienda de Libros — Diseño de Base de Datos

Proyecto de diseño de base de datos relacional para una tienda de
libros que gestiona inventario, clientes y ventas. Incluye:

- **Normalización paso a paso (1FN → 2FN → 3FN)** de una tabla inicial no
  normalizada, con justificación de cada descomposición.
- **Diagrama Conceptual de Entidad-Relación** (notación de Chen) con
  entidades, atributos y cardinalidades.
- **Diagrama UML de Entidad-Relación** con atributos tipados, claves
  primarias/foráneas y multiplicidades.
